# Decode notes

Cumulative working notes from static analysis of the Reference Build: addresses,
table locations, structure interpretations, and cross-references into the
Reference Disassembly. One file per subsystem, appended to as milestones pull
new decodes (ADR 0014).

Addresses and structural findings belong here. Actual game bytes do not — data
extracted from the Reference Build goes to the gitignored `/payload/` via the
`lab` tooling, never into Git.
