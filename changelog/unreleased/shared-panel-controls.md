**Mercenary III's panel takes the pointer, and Mercenary III runs.** Mercenary III now uses Damocles's panel controls. Tap the head's name to open it, its ends to rotate the Carried Stack, and the open centre box to page and read, or use the wheel. R, or a tap on the run lamp, latches running at the original's recovered pace: 5/3 the walk and 3/2 the turn. The run lamp lights, and a Save keeps the toggle. The run lamp takes a tap on Damocles's and Targ's panels too. All three Titles' panels share one set of controls (#599).
