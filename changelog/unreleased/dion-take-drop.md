**Mercenary III's Take, Drop and Carried Stack work by key.** `T` takes the object in reach, `D` drops the head object onto a support or the ground, and `[`/`]` rotate the stack, with the panel label scrolling as in the original. Every object follows the original rules: fixed and heavy objects, capacity and the BRIEFCASE's overflow. Pickup scripts and other effects not yet ported do nothing and are noted in the Shell Console. Earlier Mercenary III Saves start a New Game (#756).
