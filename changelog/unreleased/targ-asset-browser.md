**The Targ Asset Browser at `/targ/assets` shows which model to edit.**
It lists every Targ object model and Surface Cell structure as the game draws
it, marked recovered, edited or authored, with its Geometry Identity,
placements and a preview, and copyable commands to adopt it and open it in
Blender. An edit whose Recovered Baseline has changed is flagged. The System
Menu links to it (#877).
