# Separate the Native Shell from the Game Surface

The Faithful Remake will keep macOS windows, menus, settings, help, file interaction, and host feedback in a minimal Native Shell outside the fidelity-governed Game Surface. The Game Surface may use separately validated stacked and wide Display Compositions, but changes in window shape must not alter camera projection, visible world content, Semantic Actions, or simulation timing; this preserves the Reference Build's characteristic presentation while providing familiar macOS interaction at the cost of limiting native UI inside play.
