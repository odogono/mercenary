# Store explicit Save Snapshots as bounded JSON

The Browser Shell stores three explicit, player-controlled Saves in localStorage. Each carries a strictly decoded, versioned JSON Save Snapshot of the Gameplay Session together with exact Data Payload provenance, schema versions, and gameplay-affecting settings; restore is rejected without changing either the live session or the stored Save when any identity or shape differs. JSON is the remaining browser-native boundary and can preserve the session's binary64 values, signed zero, collections, optional state, and 64-bit random stream through explicit representations, so ADR 0012's deterministic CBOR choice is retired for saves while its integer-preserving JSON content contract remains. Version 1 deliberately has no migration or best-effort fallback: exact restoration and deterministic continuation are the promise, and a future compatibility policy must be chosen deliberately rather than inferred from permissive decoding.
