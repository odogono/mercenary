# Share numeric sky helpers with Dion-owned presentation data

Superseded in part by [ADR 0077](0077-share-one-enhanced-planner-across-damocles-and-mercenary-iii.md): Enhanced shares one planner across Damocles and Mercenary III, which starts in Enhanced.

Accepted for [I3 / #710](https://github.com/odogono/mercenary/issues/710), 2026-10-02. R7 independently establishes that Mercenary III uses the celestial rotation, phase and star-band arithmetic already implemented for Damocles. Dion supplies its own admitted records and current view inputs to those pure helpers; both Titles continue to emit the existing Frame Description and use the shared renderer. The star helper accepts the numeric `Starfield` subset rather than requiring a fabricated Damocles source identity.

Dion owns its System centres, draw lists, palette words, star field, tail geometry, full rotation phases and atmosphere/context selection. Its craft arithmetic reads separately pinned Dion tables. Damocles's moving comet, clock, Body transfer and Session State are not imported. Dion's general world camera and model/token adapter remain Title-local because their input ownership and original grammar differ. This extends the mechanism boundary in ADR 0043 without coupling either Title's content identity or Saves; [the implementation contract](../dion-tourcraft-content-contract.md) records the reuse dispositions and verification. I4 retains flight scheduling, live state updates and Save migration.
