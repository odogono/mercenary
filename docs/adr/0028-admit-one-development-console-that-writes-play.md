Extended by [ADR 0050](0050-travel-from-a-sessionless-atlas.md), which admits authored Atlas Travel through the Gameplay Session.


The Browser Shell gains a Shell Console whose commands may write gameplay state — teleporting to a cell or a Room, restoring a Save — through the Gameplay Session's own actions and the preference and Save cores, never around them. Commands that adjust presentation likewise go through presentation-owned interfaces: setting Targ local time offsets the Targ Orrery and Benson Panel together without writing Session State. It is admitted as a development tool rather than as play: it reaches what no player action can, so its commands are never part of a trace. ADR 0018 leaves the existing diagnostics alone because they touch no gameplay state; this one can, so it is named here rather than assumed under that exemption.

The console is the only Browser Shell surface that writes play — every other is presentation-only — and the separation from traces is structural rather than enforced at runtime: replay runs on its own page, no recorder exists, and a test holds the console's vocabulary and the trace decoder's apart so the day a recorder arrives is the day it fails.
