# Drop pre-release prototype Save migration

Accepted by the user, 2026-10-03. Mercenary is not live, and keeping Saves from earlier browser prototypes working is not a release requirement. The TOURCRAFT milestone will support complete Save and Session Resume for newly created expanded-game sessions and refuse incompatible development records with a clear explanation to start a New Game. This supersedes the migration clause of [ADR 0065](0065-promote-bounded-dion-catalogue-content-through-an-explicit-export.md), ADR 0068 and ADR 0070 and the migration-specific parts of D2/#704, R8/#709 and I4/#711. It concerns browser prototype records; original-game Save-format decoding remains outside this milestone.

Retire R8a/#735 and its eligibility, inverse-history and canonical-reference proof gates. R8b/#737 still defines every future-affecting field, its coherent New Game seed with provenance, validation and direct restoration from an expanded Save Snapshot. Keep #736's face-selection tag and four cursors, reconstruction before the first reader, and all 33 taxi checkpoints as expanded-game regression and same-schema Save/Resume comparisons. Flight, free waiting, campaign effects and first-frame/ordered-future fidelity remain required.

Refusal must preserve stored records and the active session until explicit New Game or a successful supported Load. Slot Saves and Session Resume remain separate and title-local; candidate validation, presentation reconstruction and write failures must not silently destroy a previous record. Existing migration research stays as historical evidence, without requiring completion of its retired proofs. This decision changes scope; it does not implement the expanded codec or claim browser comparisons have passed.
