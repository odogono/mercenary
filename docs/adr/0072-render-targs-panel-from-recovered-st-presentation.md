# Render Targ's panel from recovered ST presentation

Targ's Panel Rendition uses the pristine ST Benson G9-ST artwork and recovered instrument and message data, narrowly amending ADR 0027's authored-only account. The ST tool now supplies this presentation as well as ADR 0063's Title Logo; the C64 Reference Build remains the authority for Targ Game Semantics. Extraction uses the pinned STX/FAT reader and records source hashes under ADR 0029. The browser writers are independently implemented from the findings under ADR 0002.

The recovered presentation does not make ST and C64 state interchangeable. An authored adapter retains the existing Session Snapshot's altitude conversion, whole speed units, bounded grid, running and aboard indications, ground warning and #715 attitude contract. It converts displayed degrees into the recovered tapes' own direction and phase; room numbers and overflow receive explicit bounded representations. The [writer investigation](../research/targ-st-panel-writers.md) specifies these mappings and their limits. The selected startup palette and completed message cells are presented without claiming the ST's palette lifecycle or per-character/VBL timing.

Targ owns its composition, fonts, field geometry, tape data and lamp mappings. It shares only the existing indexed-plane and colour primitives with Damocles and Mercenary III. The authored Damocles Panel Rendition dressing Targ and Flyover's fallback remain under ADR 0027; Damocles's actual recovered panel remains under ADR 0071. Display Composition, Panel Rendition, controls and semantic readouts remain available. Native 320 × 64 artwork replaces the authored 170-pixel panel beneath the world view.

Acceptance combines pristine source-copy checks, arrival static-region comparisons, bounded native writer samples and deterministic browser images for maintainer review under ADR 0011. It is a presentation adoption with authored adapters, not full dynamic writer or cross-edition gameplay parity. Raw media, RAM and captures stay Restricted Material.
