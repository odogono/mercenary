# Gate sensitive publication on qualified review

Amended by [ADR 0093](0093-publish-the-app-to-github-pages-from-this-repository.md): the app is published to GitHub Pages from this repository, which is public. The original decision follows.

One maintainer may conduct both Reference Build research and the Independent Implementation, while the repository and Restricted Material remain private by default. Independently authored engine code, safe documentation, and synthetic demonstrations may later pass a maintainer publication checklist, but Reconstructed Payloads, game-specific research, original branding, comparison media, and the complete Initial Release require written qualified-counsel clearance; this avoids a disproportionate clean-room organisation for a solo project while keeping difficult-to-reverse publication decisions externally gated.
