# Make Reference Viewport clipping and the Benson Display canonical

Production clips ordinary and Distant Structure lines to the four borders of the rendered frame after mapping the Reference Viewport into it, and presents Benson Messages through the Reference Build's persistent 23-cell burst display. The display consumes the recovered padding words that transcript text omits, so a complete short message remains intact during its reading hold; its active scanout stays at the recovered 50 Hz so the browser's six-times script acceleration cannot reduce a burst to four or five rendered frames, while the silent `$E1` wait retains the full script scale. These presentation behaviours supersede the frozen Trace Oracle's unbounded projected lines and progressive message ticker: the Projection Replay Gate explicitly requests unclipped lines, while the Benson, Session, and Navigation Replay Gates explicitly request the test-only legacy ticker, so those traces continue to grade their accepted arithmetic, ordering, and game semantics. Far Points, Arrival Narration, and Browser Shell notices are outside this decision and keep their existing presentation paths; no runtime preference exposes either legacy mode.
