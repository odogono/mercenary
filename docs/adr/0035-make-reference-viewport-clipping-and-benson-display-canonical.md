# Make Reference Viewport clipping and the Benson Display canonical

Production clips ordinary and Distant Structure lines to the centred, scaled Reference Viewport and presents Benson Messages through the Reference Build's persistent 23-cell, 50 Hz burst display. These recovered presentation behaviours supersede the frozen Trace Oracle's unbounded projected lines and progressive message ticker: the Projection Replay Gate explicitly requests unclipped lines, while the Benson, Session, and Navigation Replay Gates explicitly request the test-only legacy ticker, so those traces continue to grade their accepted arithmetic, ordering, and game semantics. Far Points, Arrival Narration, and Browser Shell notices are outside this decision and keep their existing presentation paths; no runtime preference exposes either legacy mode.
