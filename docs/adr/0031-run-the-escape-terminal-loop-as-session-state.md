# Run the Escape terminal loop as Session State

The Interstellar Ship Field the Escape presents is Session State owned by the Gameplay Session, stepped inside `advance` and carried in the Save Snapshot, rather than an animation a renderer owns. It looks like presentation and is not: the Ending Phase's move from 1 to 255 is written by the field's own colour sequence when that sequence reaches its last pair, so the field is what decides when the Ending matures, and every later expiry rewrites the same value. A renderer-owned field would either be unable to make that write or would have to reach back into Session State to make it, and the seam ADR 0007 draws would be the thing that broke. The acceptance scenarios ask for exact deterministic continuation from a Save taken in phase 1 and in phase 255, which a presentation-side animation could not offer either. The Session Snapshot therefore carries the colour pair and the already-projected points, and `planFrame` stays a pure consumer that branches on their presence the way it already branches on a dark Room.

The field's respawns draw from the Reference Build's own shared two-byte generator, ported to TypeScript, rather than from the session's existing randomness. The two are not interchangeable: the decoded generator is carry-sensitive, every invalidity branch enters a respawn with the carry set, and the recurrence's character is decoded behaviour rather than an implementation choice. Because the Reference Build never seeds or resets it, there is no first-frame state to reproduce and no possibility of matching an original run point for point; what the port buys is the right distribution and an exact, restorable continuation within one Gameplay Session. The laboratory already held this recurrence in Python, so the two agree through a tracked fixture that each side re-derives, and either drifting fails its own suite rather than surfacing later as an unexplained difference. The generator's two bytes are seeded once at the Ending from the scripts' own random state and then ride the Save with the rest of the continuation boundary.

Three details the decode does not state are chosen here rather than left implicit, and are named in `session/shipField.ts` so a later observation can correct them in one place: the byte order within a respawn's 24-bit source, which the decode's own account of Y reusing X's first-draw residue forces; the carry between the seven consecutive draws, chained from each to the next; and the rounding of the native multiply that accelerates the depth delta, which is left in exact arithmetic because choosing a mantissa rule would invent a fact the decode does not carry. Every value the decode does state — the delta, both multipliers, the exponent the acceleration stops at, the projection centres and bounds, the draw counts and ranges, and the colour schedule — is honoured.

The field is not behind a Presentation Preset. It is recovered behaviour rather than an authored addition, so unlike ADR 0025's Targ Star Sphere it presents identically under Authentic and Enhanced, and ADR 0025's orrery has nothing to say about a frame the terminal loop owns.
