# Retain camera geometry and accepted projection in Frame Descriptions

Superseded in part by [ADR 0077](0077-share-one-enhanced-planner-across-damocles-and-mercenary-iii.md): Enhanced shares one planner across Damocles and Mercenary III, which starts in Enhanced.

Accepted, 2026-10-01, for [#672](https://github.com/odogono/mercenary/issues/672). The shared Frame Description is camera-first, but each polygon and line also retains the Title planner’s exact accepted screen geometry; screen-space stars remain explicit points. Carrying both costs additional frame data, but avoids making GPU projection or a second CPU projection the authority for Authentic while retaining geometry for future depth support: camera-only would risk changing accepted raster output, and screen-only would discard the geometry the shared renderer needs to grow.

Both presentations consume the same ordered description and Title-resolved palette bands. Mercenary III’s first Enhanced path uses flat colours and painter order through the common renderer used by Damocles, with strokes and stars retaining their logical size; its panel remains outside that renderer. Mercenary III defaults to Authentic and persists its own choice, with graphics failure returning the same session to Authentic until an explicit retry, without replacing the stored choice. Damocles’s existing GPU input and presentation remain intact through a compatibility seam; migrating its planner and Targ’s follows ADR 0060 separately.
