# Keep one browser session resumable until New Game

The Browser Shell maintains one Session Resume in localStorage so returning in the same browser automatically restores the current Gameplay Session, including an Ending, until the player chooses New Game. It uses the same bounded JSON Save Snapshot and exact environment validation as ADR 0026's three player-controlled Saves, but remains a separate record that never occupies or overwrites a Save slot; version 1 has no migration, partial restore, or best-effort compatibility.

One browser page owns the Session Resume under an exclusive Web Lock, with an ownership token fencing every step, action, and write; localStorage is durable state rather than an ownership protocol, and cross-page notification only prompts the displaced owner to pause. A second page may explicitly take over after the responsive owner flushes and stops writing, while an unresponsive owner's latest checkpoint may be up to one second old. Where secure Web Locks or storage are unavailable, play and manual Saves remain available but Session Resume is disabled visibly rather than degraded to last-writer-wins persistence.

Changed state is checkpointed at most once per second, after successful Semantic Actions, and at New Game, Save restore, Ending, System Menu, hidden-page, and page-exit boundaries. Normal reload therefore restores the latest state, while abnormal termination can lose at most one second. New Game is a two-press System Menu action that replaces the live session and its Session Resume while preserving player Saves and presentation preferences; Browser Shell overlays, focus, held input, command history, and transcript are not restored. If the immediate Session Resume write for New Game or Save restore fails, the requested replacement still happens, the stale record is removed where storage permits, and Session Resume is disabled visibly for that page.

This supersedes ADR 0028 only where it calls the console the sole Browser Shell surface that writes play. New Game and Save restore are whole-session replacements available through ordinary shell chrome; unlike the console's development mutations, neither makes the resulting session ineligible for traces.
