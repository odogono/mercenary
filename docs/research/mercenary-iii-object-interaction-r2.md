## Head, open panel and description are separate owners

Dion Open (`$4D63C`, original keypad Enter `$72`) reads stack count `$563C` and head byte `$563E`, searches the 36 definition records at `$4D6EA`, and does nothing for an unmatched object or an already-open identity. A match copies the four-byte descriptor to `$6F0E..$6F11`, prepares the palette/artwork, starts reveal64 and requests sound. Category2 additionally initializes section offsets and the selected section. The frame input dispatcher `$4D848` refuses panel commands while reveal `$53950` is nonzero. This gate applies to Open too; stack actions have their separate signed label-scroll gate.

Read/Next/Previous dispatch through the **already-open descriptor**, regardless of the present head. Category2 Read (`$4DD50`, key `$66`) requires no passenger and no existing description continuation, then copies selected-section text address plus8 into `$722C`, sets continuation `$7230=1`, and records the open object/section in `$6F06/$6F07`. Next/Previous (`$4DD84/$4DDB8`, `$4E/$4A`) select sections with wrap, change the title/selected pointer and request sound. They do not retroactively retarget a text stream already in `$722C`. TAXICARD has a dedicated dispatch before the category switches; ordinary category5 BUS PASS has no corresponding keypad command branch.

Drop compares the removed head identity with `$6F0E` at `$5592A`. Only a match clears the four-byte descriptor and starts the category0 logo reveal. Removing a different head preserves the open card. This path does **not** clear `$722C`, `$7230` or the description object's recorded identity. Take/rotation select a new name but do not run Open automatically. A snapshot cannot derive open-panel or active-description ownership from the current head.

## Content and presentation readers

The stack name comes from the acquired identity's record at the object table `$4BD10`, sixteen bytes before that record. Forward rotation/Drop select a +16 scroll; Take/reverse rotation select −16. `$4E3A6..$4E446` shifts one character per invoked step into the retained sixteen-character buffer `$4E380`, advancing the signed count toward zero. Preserve that partial buffer, direction/count and selected label source for first-frame reconstruction. Empty-stack Drop selects the sixteen-character empty label. `$4E328` also patches numbered key/explosive names for slots30–39/64–73, so immutable text alone is not a universal label contract.

The already-established [panel reader](../../research/mercenary-iii-st/m3lab/panel.py) recovers the separate reveal: 64 tick invocations, first scroll-out/black, palette exchange at32, then incoming32 artwork rows; category5 adds its text when finished. Label motion, centre reveal and message-bar motion have distinct cursors. Accepted eleven-tick frame timing does not reduce any of them to an arbitrary browser animation duration.

TAXICARD104 and BUS PASS103 are category5, bands4/8, with source colour pairs `[$640,$760]` and `[$400,$600]`. ACME135 has no definition in this table. MARGARETS LETTER220 is category2/band42, colours `[$600,$755]`. It has four selected section records at `$7773A`, `$77762`, `$7781A`, `$778D7`; their packed message-row counts are **1,7,6,1**. Section navigation follows the byte before each record (40,184,189,0), while message continuation follows the packed decoder's returned cursor. A zero packed terminator ends one row; the following zero byte ends the section. Do not truncate the seven- or six-row sections at their first row, or confuse section selection with streamed row continuation.

`$55A86` sets message mode2 (`$723E`), decodes the next packed row, restores the message-age seed, sets busy1 and advances `$722C`. At section end it marks scroll-out, clears continuation and pads the row. The scheduler checks busy first, then description continuation, then the queued script/VM. Thus opening/reading a letter adds actual future message timing and can defer a queued pickup response. Negative continuation uses a separate cleanup return. The shared [packed-text decoder](../../research/mercenary-iii-st/m3lab/text.py) retains six-bit packing, centring, live substitutions and the `^2` carry quirk; promotion must admit the selected rows and their token dependencies rather than a single display string. The letter's token vocabulary is checked in the restricted observer, without publishing its full expression-bearing text here.

`$55B6A` is the interaction sound helper: unless `$70A2` suppresses it, it sets priority3 and the B-programme pointer; the `$72A8` guard additionally governs immediate mixer writes. It does not itself select or decode a description. Take requests this helper during stack insertion **and again** after pickup-table handling; Drop requests it during head replacement where present and during placement; rotations request it with label selection. Open/Read/Next/Previous have their own sound sites. Save reconstruction must paint the retained outputs without replaying these event sites.
