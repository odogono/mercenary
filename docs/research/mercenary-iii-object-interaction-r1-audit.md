## Sources and interpretation

The authority for a Dion rule is the original engine and its retained outputs. The [initial static report](mercenary-iii-object-interaction-evidence.md), [R1 method and pins](mercenary-iii-object-interaction-r1.md#method-and-authority), and ignored `restricted/mercenary-iii-770/{fixtures.py,distance_controls.py,results.json,reuse/verify-handoff.py,reuse/handoff-verification.json}` establish how each observation was obtained. Family `manifest.json` files select the actual runs, input writes, source RAM/snapshot hashes and CPU setting. Generated run directories alone are not the selected evidence. [ADR 0002](../adr/0002-separate-rom-research-from-implementation.md) governs independent interpretation rather than machine-code translation.

The accepted route writes the original key/joystick mailboxes at loop tops, retaining the original accepted eleven-tick wait adaptation. It is an ordinary New Game route in its pose, Residence and selection, but is not physical keyboard/IKBD delivery. Synthetic handler fixtures inject selection/state before dispatch; synthetic candidate fixtures inject list/positions and then let the original builder, writer and next action run. Earlier variable-cadence RAM remains numeric/static comparison evidence, rather than being relabelled as eleven-tick play. These distinctions are stated in the [handoff method](mercenary-iii-object-interaction-r1.md#method-and-authority) and [numeric replay](mercenary-iii-object-interaction-r1.md#read-only-numeric-replay).

The verifier's 265 explicit pin/outcome assertions and sampled cadence checks describe their actual checks. Many refusal checks compare the resulting stack; they do not assert byte-for-byte preservation of every future-affecting owner. `read_results.py` observes XYZ, group, zone, state and four-byte Residence for a named set of slots, while the twenty-entry staging assertions specifically check every entry's XYZ and group. Consequently, an unchanged stack alone is not a complete refusal-transaction or placement-metadata proof. Sources: ignored `reuse/verify-handoff.py` and `read_results.py`, and the [published verification scope](mercenary-iii-object-interaction-r1.md#method-and-authority).
