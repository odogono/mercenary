## Representation and admission

Keep the versioned JSON record and `snapshot: { remainder, snapshot: state }` envelope from [ADR 0026](../adr/0026-store-explicit-save-snapshots-as-bounded-json.md). Reserve `schemaVersion: 2`, Title `dion`, opening Destination `metis` and the verified complete served expanded content identity. Body changes do not change that Destination or storage key. Refuse schema 1 or another content/program identity before candidate construction, preserving stored bytes and the active session. [Persistence transaction](mercenary-iii-tourcraft-persistence.md#snapshot-admission-storage-and-replacement-transaction)

The notation below is part of the contract:

| Type | JSON representation and exact bounds |
| --- | --- |
| `u8`, `u16`, `u32` | Integer number in `0..255`, `0..65535`, `0..4294967295`, respectively. Preserve bits; interpret signedness at the recovered reader. Never truncate/clamp decoder input. |
| `count` | Nonnegative safe integer, maximum `9007199254740991`; stop capture with a diagnostic before increment would exceed it. |
| `packed` | `u32`: signed exponent high word and signed mantissa low word, in units of `$1000`. This is the original arithmetic representation, not a decimal speed or host float. |
| `XYZ` / attitude | Exactly three `u32` position bits / three `u16` angle bits. Signed positions are interpreted as two's complement. Mask angle only at the owning writer; opening yaw 1024 must survive admission. |
| `Ref` | An admitted semantic content key, never an arbitrary RAM address. A cursor is `{ content, next }`, where `next` is an integer index into the exact decoded boundary table. Require the correct instruction/record/stream kind. Only an expressly allowed inactive owner may be `null`. |
| Fixed array | Exact length and integer element type; no sparse arrays, duplicate keyed owners, omitted fields or extension keys. No implicit zero fill. |
| Variable array | Bound by its content list, eight live VM returns, 246 carried residents or the event limits below, as applicable. Preserve order. |

`remainder` is finite in `[0, 0.02)` after the existing boundary-epsilon normalization. No NaN, infinity, negative zero disguised as an unsigned field, fractional integer, numeric string or overflow is admitted. The decoder must enforce a record byte limit before parsing, then fixed field/list/string limits. A proposed ceiling is 256 KiB for one complete record, with at most 512 pending logical event batches, 64 ordered PSG writes per batch and 48 decoded message cells. If a legitimate capture exceeds a ceiling, fail explicitly and investigate the bound; do not silently drop events or truncate a message. These limits are schema design bounds, not recovered Atari memory sizes.

Reference admission uses I3's complete dependency set, including original instruction, return, packed-text, playback pair, pilot-duration, trajectory and sound-stream boundaries. The idle/bootstrap returns must be included: coherent opening PC is `$6FF57`, and its one live return is **`$766D5`**. Merely checking an address lies in RAM, checking a routine's numeric interval, or allowing every `$6FD44 + u16` target is insufficient. [Script decoder](../../research/mercenary-iii-st/m3lab/scripts.py), [own-title observer](../../research/mercenary-iii-st/m3lab/snapshot_owners.py)

Define the new browser's elapsed tick/frame counters as zero at this boundary, while preserving all captured original state, clock fraction and phase. Do not apply the old thirteen-tick alignment or seed from historical `world.json` mutable values.
