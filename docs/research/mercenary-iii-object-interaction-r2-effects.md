# Mercenary III: R2 pickup response effects

Research for [R2/#771](https://github.com/odogono/mercenary/issues/771), part of [#756](https://github.com/odogono/mercenary/issues/756), 2026-10-04. This companion to the [interaction plan](mercenary-iii-object-interaction-plan.md), [initial evidence](mercenary-iii-object-interaction-evidence.md) and [R1 handoff](mercenary-iii-object-interaction-r1.md) closes the three pickup-response **VM graphs** and executes their default and selected synthetic futures. It changes no gameplay, Data Payload, Golden Trace or playable admission. These remote objects are absent from current TOURCRAFT model bindings; their synthetic acquisition does not prove a New Game route.

The subsequent [acceptance audit](mercenary-iii-object-interaction-r2-audit.md) independently replays all eighteen retained families and adds explicit nested-Return, availability, native timer-write and ordered-request assertions. It also documents the corrected `child-idle` run's capture-list difference from the retained regeneration helper; use its tracked observer to verify the exact accepted evidence before regenerating original runs.

All three opening availability bytes are `$A0` (available, queueable, nonrepeatable). None of these graphs executes object-bit opcode `$20`, account opcodes, encounter request `$2A` or model-swap-A `$27`. **This absence is a decoded-graph result**, not proof that all other object readers are inert. ORE changes flags22/9 that the [default campaign](mercenary-iii-tourcraft-campaign.md) reads, so its effect is not an isolated extra message. Admitting it would require scope review of campaign alternatives and model replacements. PCB needs persistence of its repeating timed future until the held predicate changes. The proposed initial cards/device and ordinary letter witness match no pickup-response table entry; this does not exclude their separate Head Commands/descriptions.

The two CHILD adjustments require the native BCD handler `$52DE8..$52E1E`. Operand `$04` adds4, clamping upper overflow to99. Operand `$85` passes **BCD85** to `ABCD`, giving31→16, rather than interpreting its lower seven bits as a subtraction of5. The lower branch clamps at1 when the native carry/zero test requires it. `$6EAB` becomes the BCD complement to100. Poll bytes must remain two original BCD owners; a guessed signed delta would change the future ID-message7 substitution. These arithmetic/clamp rules are static except for the executed27→31→16 path below.

Model-swap-B `$52FC8..$52FE0` reads the live model-table pointer at `$4BD10`, copies its word at offset `$278` into `$C2`, and its word at offset0 into `$1B4`. It does not clear the two handling bits that model-swap-A clears. This is a model-table mutation, not object Residence or Carried Stack mutation. Synthetic ORE executes this handler and checks both copied words: `$C2` changes`$0308→$3D6A`, `$1B4` changes`$8514→$0308`. These are native table words, not promoted model IDs; rendering or access to those replacement models is not established.

## Original execution and scheduler controls

All execution here is **synthetic original-program execution**. The seed is R1's naturally reached outdoor `route-32/f140`; the controls inject selected identity/distance and scheduling fixtures, then deliver Take through the original key mailbox. They normalize VM PC/stack/active/busy/queue for idle cases explicitly; active cases use the original idle self-jump with flag6 set. Original Take, response lookup, launcher, interpreter, tick, message and timer handlers execute thereafter. No physical keyboard delivery, ordinary remote acquisition, original audio fidelity, browser behavior or Save equivalence is claimed.

`controls.py` imports R1's pinned `harness.py`, redirects new artifacts into `restricted/mercenary-iii-771/effects/`, and retains every generated debugger command in each run. Wait instrumentation delivers eleven game ticks per complete wait and masks tick delivery during frame execution. `read_results.py` verifies every retained consecutive top gap is `(one frame, eleven ticks)`, every logged within-frame reader agrees with its top tick, and all captured SR interrupt masks remain7. It reads RAM/logs rather than simulating outcomes. A first incorrectly named idle trial inherited the active opening VM; its raw run is retained but the family manifest selects the corrected synthetic control.
