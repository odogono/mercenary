Let `s(a)=sin(((a & 1023)+0.5)*2π/1024)` and `c(a)=s(a+256)`. Use presentation roll `a=$7132`, pitch `b=$7134`, yaw `y=$7136`; every sine/cosine below uses that half step. The general view matrix V has rows depth/u/v:

```text
[ cp*sy,                sp,        cp*cy                 ]
[ sr*sp*sy + cr*cy,     -sr*cp,     sr*sp*cy - cr*sy     ]
[ sr*cy - cr*sp*sy,      cr*cp,    -(cr*sp*cy + sr*sy)   ]
```

Here `sr=s(a)`, `cp=c(b)`, etc. MIII's packed long is signed mantissa-low-word /4096 times 2 to the signed exponent-high-word.
```text
R = [ cl,       0,   -sl     ]
    [-sl*sp,   cp,   -cl*sp  ]
    [ sl*cp,   sp,    cl*cp  ]
```
