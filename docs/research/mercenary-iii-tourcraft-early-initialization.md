The source remains Title `dion`, opening Destination `metis`, schema 1, program `4e8b74122910bcaa109b944eebb6f0ec18fdeb1175c34eea3c932d0e1b18b62c`, complete served-content digest `c50b402c04c70ab74f95a938c0f867e740ea843157e514764f2bceb84a2f44ed`. The promoted comparison facts are separately bound to digest `d31490d7ba44a08949f71267884f1e290074acc5885fdfae747f7aeefcfdf611`. Neither current schema-1 content nor arbitrary foreign identities are admitted by this research loader.

The early history domain considered here is ordinary New Game followed by supported I2 card, taxi and foot inputs, with its fixed unpaused 32/1600 clock, no time injection, and a monotone history before the first election threshold. It has no TOURCRAFT boarding, Body transfer, space-rate writer, actor firing or excluded flags 10/22. This is a **history definition**, not an executable source eligibility predicate: a decoder-valid record with `seconds < 32400` is insufficient, and the 33 named records are not an eligibility allowlist. A total constructor still needs source-only consistency checks and a sufficient-history or authorized canonical rule for records outside the measured prefixes. [Existing validator and cross-field limits](mercenary-iii-tourcraft-taxi-migration.md#source-validator-and-eligibility-boundary)

Both collision histories are members of that ordinary domain, not fabricated valid-looking snapshots. The counterexample is at 126 game seconds. Rejecting it because it is a partial-frame source, or refusing every taxi Save, would narrow the accepted contract without evidence or authorization.

Every record passes the archived Save decoder/restored-session comparison and the separate Session Resume reader/restored-session comparison. It drains historical sound writes at the capture boundary and never writes browser storage.

Alongside each replay, the existing independent [R6 VM model](../../research/mercenary-iii-st/scripts/taxi-history-model.ts) consumes ticks, frame calls and actual external requests. Observational wrappers preserve the source methods' state and results. A separate [face model](../../research/mercenary-iii-st/scripts/taxi-face-model.ts) consumes that model's busy/flag-13 selector after the VM and before mode-specific service/admission, using the promoted original sequences and coherent initial face seeds. Each invocation checks the independent VM against the source PC, flag 13 and busy state. The face selector uses display mode zero, justified for these single-row messages by the original mode writers in the owner audit. This is an uninterrupted **research reference for these owners**, not a complete expanded browser Gameplay Session or original-machine rerun.

For rotation, a separate per-tick array replay starts with the explicit legacy phase alignment `R7initialPhase[i] + 13 * rate[i]`. At each checkpoint all 32 values are compared against an integer-arithmetic source-tick construction, for **1056 matches**; METIS additionally equals the preserved source sky phase. This checks the declared aligned reference. It does not turn that alignment into a claim about the unavailable old whole-RAM opening capture. Clock accumulator/day/seconds, remainder and source phase are untouched. [Alignment provenance](mercenary-iii-tourcraft-early-owner-audit.md#clock-and-all-32-body-phases)

## The early collision

Use the archived `sol/selected` operation list, stopping immediately before its last `press('board')`. This is the real approach after the earlier failed B attempt, with live intent already idle and a called, stationary taxi. The prefix has 526 operations; its JSON digest is `f540601a8bec8fabe815da4e385c36ee15dad09e4d7fcfdb411f58437645c36e`. Preserve those individual advance calls rather than coalescing their floating-point remainder arithmetic.

1. Replay that common prefix and two additional ordinary frames into two independent fresh sessions.
2. In history A, press B and advance one frame; then advance 23 ordinary frames.
3. In history B, first wait one additional frame, press B and advance one frame; then advance 22 ordinary frames.
4. Capture both sources at the resulting identical tick and drain past sound writes. No state, clock, pose or source record is injected.

Boarding's accepted ID `$28` occurs after that frame's face update: at tick 6050 for A, 6061 for B. The padded message runs 251 ticks, so B becomes idle at capture tick 6312, nine ticks after its last face update at tick 6303. A was already idle at that update. The serialized message's age saturates at 250; after idling, it no longer retains the precise completion tick. Boarding itself adds no sound cue that would distinguish these saved states.

Two additional ticks reach the next atomic frame; both references then select base, their complete face states and complete source records agree, and 600 subsequent idle frames agree with identical ordered sound writes. This is evidence **against** treating the pair as a proved observable-future incompatibility. It leaves a precise omission question: can a retained face output ever be read before it is overwritten under all admitted restore and draw paths? The current inventory has not proved that exemption. A frame planner can be asked to draw a saved moment before an advance, so next-frame convergence alone is insufficient as a universal omission proof.

## Consequence and next acceptance checks

A source-only function cannot reproduce both retained `$A5` outputs for the identical record above. There are two evidence-backed routes to a completion contract: prove the output is disposable before any first-frame or future read throughout the eligible domain, or return this bounded failure to D2 for an explicit early canonical policy. The experiment selects neither route on D2's behalf. It supplies neither authored defaults nor blanket taxi refusal.

The remaining browser acceptance must independently replay each actual input prefix into an expanded New Game session, compare all constructed owners and the first indexed frame/Frame Description, panel and candidate, then continue the recorded suffix with equal live intent and ordered messages/PSG writes. Include the partial-tick collision and message completion on either side of a frame, pending B/admission, all 33 existing names, later campaign thresholds, and the actual normal-input TOURCRAFT boarding → launch → space → Body entry → automatic exit → on-foot continuation. Construct and validate a candidate before replacing the active session; failed decoding/construction must preserve exact source storage bytes and independent Save/Session Resume ownership. [Full matrix](mercenary-iii-tourcraft-taxi-migration.md#required-33-control-matrix-and-expanded-comparison)

Executed here: pinned source and promoted identity checks, 33 independently generated prefix comparisons, 66 source codec/restored-session round trips, 1056 aligned rotation comparisons, independent finite face replay, the ordinary full-record collision, its two codec paths, and 600 agreeing post-convergence frames/events. Not claimed: a total source eligibility classifier, complete added-owner constructor, visible collision, original-machine rerun, complete expanded browser codec/runtime, TOURCRAFT continuation, storage transaction or #709 completion.

Validation: the six focused Dion persistence/history/canonical/content/frame and early-initialization test files passed **46 tests, 50645 assertions**. Web TypeScript checking, ESLint for the new test, formatting for the new artifacts, relative report-file links and `git diff --check` passed.
